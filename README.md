# Oreogenesis

Oreogenesis is a Terraria (tModLoader) mod focused on automated resource generation through crystalline growth systems.

## Core Concept

Instead of traditional farming or mining, Oreogenesis introduces **Geode Blocks** that generate **crystal growths** over time.

Players can:
- Place geode blocks underground
- Allow crystals to grow naturally
- Harvest crystals manually or via wiring/actuation
- Process crystal shards into usable materials

## Features (WIP)

- Geode-based crystal growth system
- Crystal harvesting via mining or automation
- Crystal Assembler crafting station
- Resource conversion through shard processing

## Planned Features

- Multiple geode types (copper, iron, etc.)
- Biome-dependent growth conditions
- Crystal growth stages (small → large)
- Transmutation Chamber for advanced resource conversion
- Automation-focused gameplay using wiring systems

## Development Status

Early development (MVP in progress)

## Goals

- Create a Terraria-native automation system
- Encourage engineering-style builds using wiring
- Provide an alternative to traditional resource grinding
